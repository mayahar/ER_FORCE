ERR Force - פרוטוקול עבודה לחוקר/ת
==================================

גרסה זו מיועדת לחוקר/ת שאינם עובדים עם קוד.
כל הפעולות מתבצעות באמצעות פתיחת תיקיות ולחיצה כפולה על קבצי הפעלה.


1. התקנה על מחשב חדש
--------------------

מה מקבלים:
תיקייה בשם ER_FORCE_Installer.

מה עושים:
1. פותחים את תיקיית ER_FORCE_Installer.
2. לוחצים פעמיים על הקובץ:
   INSTALL_ON_WINDOWS.cmd
3. לא להריץ כ-Administrator אלא אם קיבלתם הנחיה מפורשת.
4. מחכים לסיום ההתקנה.
5. בסיום תיווצר על שולחן העבודה תיקייה בשם:
   ERR Force Tools

אם ההתקנה הסתיימה אבל לא רואים אייקון להפעלת האפליקציה:
1. פותחים את ERR Force Tools.
2. לוחצים פעמיים על:
   Run ERR Force.cmd


2. הכנת Tobii / מנטר עיניים
----------------------------

חשוב:
בכל מחשב שבו משתמשים במנטר עיניים פיזי צריך להתקין גם את תוכנת Tobii/driver.
האינסטולר של ERR Force מתקין את האפליקציה ואת חבילות Python, אבל אינו מחליף את
תוכנת Tobii שמזהה ומכיילת את החומרה.

מה עושים בכל מחשב חדש:
1. מתקינים Tobii Eye Tracker Manager / Tobii driver.
2. מחברים את מנטר העיניים למחשב.
3. פותחים את Tobii Eye Tracker Manager.
4. מוודאים שהמנטר מזוהה.
5. מבצעים calibration למסך הספציפי.
6. פותחים את ERR Force Tools.
7. לוחצים פעמיים על:
   Verify Eye Tracker.cmd

פירוש תוצאות:
- אם מופיע שה-eye tracker מוכן, אפשר להריץ ניסוי.
- אם מופיע NO TRACKERS FOUND, האפליקציה קיימת אבל Windows/Tobii עדיין לא מזהים
  את המנטר. יש לבדוק חיבור USB, דרייבר, Tobii Eye Tracker Manager וכיול.


3. הפעלת ניסוי
---------------

לפני התחלה:
1. מוודאים שמנטר העיניים מחובר ומכויל.
2. מוודאים שהסטיק/ג'ויסטיק מחובר אם הניסוי דורש זאת.
3. פותחים את ERR Force Tools.
4. לוחצים פעמיים על:
   Run ERR Force.cmd

בתוך האפליקציה:
1. מזינים או בוחרים participant לפי פרוטוקול המחקר.
2. מתקדמים במסכים לפי סדר האפליקציה.
3. מריצים את המשחק/משימת הטיסה.
4. בסיום מוודאים שהאפליקציה מציגה תוצאה או מסך סיום.


4. קינפוג סטיק / ג'ויסטיק חדש
------------------------------

מתי צריך:
- אם מחברים דגם חדש של joystick/throttle.
- אם הצירים לא מגיבים נכון.
- אם המצערת הפוכה או לא מזוהה.

אם משתמשים ב-Logitech Extreme 3D:
בדרך כלל אין צורך בקינפוג ידני. הפרופיל כבר כלול במערכת.

לקינפוג סטיק חדש:
1. מחברים את הסטיק למחשב.
2. פותחים את ERR Force Tools.
3. לוחצים פעמיים על:
   Configure Joystick.cmd
4. FlightGear ייפתח במצב קינפוג.
5. בתפריט העליון נכנסים ל:
   File -> Joystick Configuration
6. אם התפריט העליון לא מופיע, לוחצים F10.
7. ממפים את הצירים והכפתורים הדרושים:
   Aileron
   Elevator
   Rudder, אם קיים
   Throttle / מצערת
8. בודקים שהמצערת לא הפוכה.
9. שומרים את ההגדרות בתוך FlightGear.

הערה:
קינפוג כזה מספיק רק למחשב שבו הוא בוצע. 


5. עורכי הגדרות
----------------

בתיקיית ERR Force Tools קיימים שני עורכים.

Fatigue Weights Editor.cmd
פותח את עורך משקלי העייפות.
משמש לשינוי המשקלים וההגדרות של הפיצ'רים שמשתתפים בחישוב ציון העייפות.
יש להשתמש בו כאשר רוצים לשנות את תרומת מדדי העיניים, קול, משחק או שאלון לציון.

Research Config Editor.cmd
פותח את עורך קונפיגורציית המחקר.
משמש לעריכת הגדרות המחקר, כגון מצב מחקר, משתתפים, ימים והגדרות ניסוי.

אחרי שינוי באחד העורכים:
1. שומרים את השינוי בעורך.
2. סוגרים את ERR Force אם הוא פתוח.
3. פותחים מחדש את ERR Force דרך:
   Run ERR Force.cmd


6. איפה הנתונים נשמרים
-----------------------

כל הנתונים נשמרים בתוך תיקיית ההתקנה של ERR Force.
אין צורך לדעת את הנתיב המדויק כדי לפתוח אותם.

פתיחת נתוני ניסויים:
1. פותחים את ERR Force Tools.
2. לוחצים פעמיים על:
   Open Data Folder.cmd

שם נמצאות תיקיות ה-sessions.
בכל session יש בדרך כלל:
- eye: נתוני עיניים, כיול, raw gaze ופיצ'רים.
- voice: הקלטות ונתוני קול.
- game: נתוני משחק/FlightGear ותוצאות משחק.

פתיחת דוחות:
1. פותחים את ERR Force Tools.
2. לוחצים פעמיים על:
   Open Reports Folder.cmd

שם נשמרים דוחות CSV ותוצאות מסכמות.

פתיחת תיקיית ההתקנה המלאה:
1. פותחים את ERR Force Tools.
2. לוחצים פעמיים על:
   Open Install Folder.cmd


7. גיבוי נתונים
----------------

בסוף יום ניסויים מומלץ לגבות:
1. את תיקיית sessions.
2. את תיקיית scores_reports.
3. במקרה של שינוי הגדרות מחקר או משקלים, גם את קבצי הקונפיג.

הדרך הפשוטה:
1. פותחים ERR Force Tools.
2. פותחים Open Data Folder.cmd ומעתיקים את התוכן לכונן גיבוי.
3. פותחים Open Reports Folder.cmd ומעתיקים את התוכן לכונן גיבוי.


8. תקלות נפוצות
----------------

אין אייקון על שולחן העבודה:
פותחים את ERR Force Tools ולוחצים על Run ERR Force.cmd.

לא מוצאים את הנתונים:
פותחים ERR Force Tools ולוחצים על Open Data Folder.cmd או Open Reports Folder.cmd.

Tobii לא מזוהה:
פותחים Tobii Eye Tracker Manager ובודקים שהמכשיר מזוהה ומכויל.
לאחר מכן לוחצים על Verify Eye Tracker.cmd.

הסטיק לא מגיב:
פותחים Configure Joystick.cmd ומבצעים מיפוי מחדש ב-FlightGear.

התפריט ב-FlightGear לא מופיע:
לוחצים F10.


9. קבצים חשובים למי שצריך לדעת
-------------------------------

הסעיף הזה מיועד רק למי שמבצע גיבוי או תחזוקה.

sessions
תיקיית נתוני ניסויים.

scores_reports
תיקיית דוחות CSV ותוצאות.

core\database_data.json
בסיס הנתונים המקומי.

core\research_config.json
קונפיגורציית המחקר.

score\fatigue_features.json
הגדרות ומשקלים של פיצ'רי העייפות.
